# 晴空歌词 · SkyLyrics

让淘宝、拼多多买来的蓝牙歌词屏，也能显示 Windows QQ 音乐的歌词；音乐暂停后，还可以变成系统信息屏。

## 为什么做这个项目

这类“智能歌词显示器”通常主打手机蓝牙连接。连接 Windows 电脑后，往往只能显示歌名，甚至没有内容。本程序从 QQ 音乐的本地歌词缓存读取当前歌词，通过 Windows 媒体通道转发到蓝牙屏。

已在 K1001 上验证歌词和系统信息轮播。其他支持相应 AVRCP 媒体信息显示的设备可能适用，尚未逐款验证，不保证所有淘宝、拼多多型号都兼容。

## 下载与使用

1. 完整解压 `SkyLyrics-v1.1.4-windows-x64.zip` 到固定目录。
2. 在 Windows 蓝牙设置中连接显示器；若设备正在连接手机，先断开手机。
3. 运行 `app/SkyLyrics/SkyLyrics.exe`，打开控制面板。无需安装 Python。
4. 使用 QQ 音乐播放歌曲，即可自动转发歌词。

请保留 EXE 旁的 `_internal` 文件夹。首次运行默认启用当前用户登录 Windows 后自启动，自启动时不弹出控制面板。可以在“常规设置”或托盘菜单取消自启动。关闭窗口只是隐藏到托盘，右键“退出”才会结束程序。

双击托盘图标，或右键选择“打开控制面板”，可再次打开窗口。重复运行 EXE 也会打开已有窗口，不会启动第二个转发进程。

## 暂停后的显示

- 默认暂停或没有音乐 **5 分钟**后，切换为系统信息轮播，每页停留 **5 秒**。
- 等待时间可设置为 0.1～120 分钟，轮播间隔为 2～60 秒。
- 可选择 CPU 使用率、CPU 频率估算、CPU 温度、内存占用率、GPU 使用率、GPU 温度。
- 恢复播放后自动回到歌词，下一次暂停重新计时。其他播放器正在播放时不进入待机显示。
- “预览待机显示 · 15 秒”会立即发送待机内容，15 秒后恢复自动模式。
- “停止转发”会停止歌词和待机内容输出；点击“恢复自动转发”重新开始。

## 自定义内容

在“自动切换”中选择“自定义文字”，在“文字编辑”中填写文字。每行一页；点击“保存设置”后生效。例如：

```text
现在是 {time}
CPU {cpu}% · 内存 {memory}%
GPU {gpu}% · {gpu_temp}°C
休息一下吧
```

可用变量：`{time}`、`{date}`、`{cpu}`、`{cpu_ghz}`、`{cpu_temp}`、`{memory}`、`{gpu}`、`{gpu_temp}`。单位与百分号自行填写；缺少数据时变量显示 `--`。每行最多 160 字，总计最多 2000 字；设备本身可能截断长文字。

右侧预览是程序正在发送的内容，不是对物理屏幕的读取。

## 硬件兼容与数据来源

程序不绑定某款 CPU、显卡或某台电脑。所有数值都在当前运行的电脑上动态采集，不使用作者电脑的型号、路径或硬件配置。

| 数据 | 来源与限制 |
| --- | --- |
| CPU 使用率、内存占用率 | psutil 读取 Windows 本机系统信息 |
| CPU 频率 | Windows Processor Information 性能计数器估算，标有 `~`；不是每个核心的精确瞬时频率 |
| GPU 使用率 | 有可用 NVIDIA 驱动工具时自动读取 `nvidia-smi`；否则读取 Windows GPU 引擎性能计数器，适用于暴露这些计数器的 NVIDIA、AMD、Intel 驱动 |
| GPU 温度 | NVIDIA 驱动工具，或兼容硬件监控工具提供的温度传感器 |
| CPU 温度 | 内置 LibreHardwareMonitor 采集组件（需管理员授权和 PawnIO），或外部监控工具的 WMI 温度传感器 |

NVIDIA 多卡时显示当前使用率最高的一张。Windows 计数器路径显示最忙引擎负载，口径可能与厂商工具不同；不支持的驱动会显示不可用。

**“CPU 温度不可用”表示没有可读取的传感器数据，不表示 CPU 故障。** Windows 不提供覆盖所有 CPU 的统一温度接口。需要温度时，可以自行运行官方 [Libre Hardware Monitor](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor)，确认其中能读取 CPU 温度并提供 WMI 数据；部分硬件读取需要管理员权限。程序会定期重新探测。若仍不可用，可取消勾选该显示项目。

本程序不捆绑、不自动安装硬件驱动，不要求系统信息功能必须有独立显卡；未安装任何传感器工具时，其他可用数据仍会显示。

## 歌词功能与兼容性

- 只读取 QQ 音乐现有本地 QRC/LRC 歌词缓存，不搜索在线歌词、不读取账号凭据、不修改播放器缓存。
- 按歌名、歌手、时长和专辑匹配版本，无法确定匹配时显示歌名。
- 支持普通 LRC、QQ 冒号小数格式和 QRC 逐字格式，输出原文整句，不包含逐字染色、翻译或罗马音。
- 歌词中的英文双引号不会截断后续内容；句间和间奏保留上一句。
- 第一行开始前或没有本地歌词时显示歌名。可先在 QQ 音乐打开歌词页，让播放器加载缓存。
- 恢复播放时若 Windows 将当前媒体来源切回 QQ 音乐，会恢复转发器的媒体会话。
- 其他接入 Windows 媒体控制的播放器可转发歌名，但歌词缓存目前仅适配 QQ 音乐。

默认歌词目录：`%APPDATA%\Tencent\QQMusic\QQMusicCache\QQMusicLyricNew`。

要求 Windows 10 1809 及以上或 Windows 11、x64。已在 Windows 11 + K1001 上验证；不同固件、蓝牙驱动、播放器和传感器版本仍可能影响效果。

## 更新、配置与退出

v1.1.4 起可在「软件更新」检查并安装新版；v1.1.1 及更早版本首次需手动更新。手动更新前从托盘退出旧版，完整解压新版到固定目录后重新启动。晴空歌词会迁移旧版自启动项，保留原有设置；不要再启动旧版 EXE。旧版来源和歌词设置会保留，新增设置使用默认值。程序目录移动后，运行一次新版即可修复已有自启动路径。

为了兼容原 K1001 Lyrics Bridge，内部配置目录与单实例标识保留旧名称。配置和滚动日志位于：

```text
%LOCALAPPDATA%\K1001Bridge\settings.json
%LOCALAPPDATA%\K1001Bridge\bridge.log
```

如果配置了 CPU 温度自动启动，卸载前先在常规设置中关闭温度自动启动。

自启动使用当前用户启动文件夹内的 `SkyLyrics.lnk`，参数为 `--background`。旧版注册表自启动项会迁移并移除，避免重复。卸载前请取消自启动、退出程序，然后删除程序目录。

硬件信息只在本地读取并转发至系统媒体通道；日志默认不记录歌词或硬件采样数值。系统媒体控件及其他媒体外设也可能看到转发的内容。程序不播放声音，也不修改默认音频输出。

## 从源码运行与构建

使用 Python 3.13 x64：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m unittest discover -p "test_*.py"
.\.venv\Scripts\pythonw.exe tray.py
```

源码树中先运行 `./sensor_host/build.ps1` 构建温度组件；这会下载并校验固定版本的上游依赖。添加 `--background` 可静默运行。打包运行 `./build.ps1`，产物位于 `dist/SkyLyrics/`。

- `tray.py`：托盘、单实例、自启动、设置持久化。
- `settings_ui.py`：图形控制面板。
- `bridge.py`：系统媒体会话、歌词和待机切换。
- `idle_display.py`：计时、内容模板与配置验证。
- `system_stats.py`：硬件探测与采样，不阻塞歌词线程。
- `lyrics.py`、`qrc_des.py`、`qrc_mask.py`：本地歌词匹配与解析。

## 界面与性能

浅蓝白界面采用原创几何图形，自定义标题栏和窄滚动条；窗口可拖动、缩放、最小化和最大化。关闭按钮隐藏到托盘。

Logo 由 GPT Image 生成，原图与生成提示词位于 `assets/`。界面参考蔚蓝档案官网的蓝白配色、斜切卡片、几何纹理，没有使用游戏角色或官方标志，不代表官方关联。

界面使用 Tk 原生控件和 Canvas，没有内嵌浏览器、视频背景或常驻动画循环。滚动由输入事件触发；窗口隐藏或最小化时停止面板数据刷新。硬件采样仅在面板可见、预览或即将/正在待机显示时启用；歌词后台转发独立运行。

## v1.1.3 温度自动恢复

在「常规设置」点击「配置 / 修复温度自动启动」，首次允许 Windows 管理员权限请求。
程序将独立 CPU 采集组件安装到受保护的 Program Files 目录，并创建当前用户的登录计划任务。
完成后，重新打开晴空歌词、移动主程序目录、重新启动 Windows 后都能自动连接温度组件。
主界面和歌词保持普通权限，登录时不弹出界面或重复请求权限。仅显示数据时采集，空闲时释放硬件。

此模式需要当前 Windows 用户为管理员，并已安装兼容的 PawnIO 驱动。
程序不保存密码，不自动安装驱动。可在同一页点击「关闭温度自动启动」移除计划任务。
主程序的开机启动和温度自动启动有独立开关；关闭面板不会关闭采集，退出主程序后采集任务保持空闲。
没有 NVIDIA App 的电脑也可以使用；AMD/Intel 支持情况取决于上游采集库和硬件。

本版修正 v1.1.2 临时授权仅在当次运行有效的问题。缺少数据时会明确显示权限、驱动或采集状态，
不会把无效的 0°C 当作实际温度。外部 Libre/Open Hardware Monitor 数据源继续支持。
