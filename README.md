# K1001 Lyrics Bridge

让淘宝、拼多多买来的蓝牙歌词屏，也能显示电脑 QQ 音乐的歌词。

## 为什么做这个项目

在淘宝、拼多多上买到的这类“智能歌词显示器”，通常主打手机蓝牙连接：连上手机、打开音乐 App，就能显示歌曲信息或歌词。但连接 Windows 电脑后，往往只能看到歌名，甚至什么也不显示。

这个项目就是为了解决电脑端的这个缺口：把 Windows QQ 音乐正在播放的逐句歌词，转发到蓝牙歌词屏上，让它在电脑旁也能用起来。

目前已实测 **K1001**。同类设备如果支持相应的 AVRCP 媒体信息显示，也可能适用，但尚未逐款验证；并非承诺淘宝、拼多多上所有型号都兼容。

程序读取 QQ 音乐向 Windows 提供的歌曲信息和播放进度，从 QQ 音乐的本地缓存读取歌词，再通过 Windows 系统媒体通道发布当前歌词。默认静默运行，只在右下角系统托盘显示绿色音符图标。

## 下载与使用

1. 在本仓库的 **Releases** 下载 `K1001-Lyrics-Bridge-v1.0.1-windows-x64.zip`，完整解压到固定位置。
2. 在 Windows 蓝牙设置中连接 K1001；如果设备连接着手机，先断开手机。
3. 双击 `K1001-Bridge/K1001-Bridge.exe`。无需安装 Python 或使用管理员权限。
4. 使用 QQ 音乐播放歌曲。程序默认启用歌词模式，自动跟随播放进度。
5. 点击任务栏右下角的小三角，右键绿色音符图标打开菜单。

请保留 EXE 旁边的 `_internal` 文件夹。程序没有主窗口；重复打开不会启动第二个转发实例。

## 托盘菜单

| 菜单项 | 功能 |
| --- | --- |
| 来源播放器 | 默认 QQ 音乐，也可选择其他系统媒体来源；选择会保存 |
| 显示 QQ 音乐歌词 | 开启时显示当前原文歌词；关闭时显示歌名 |
| 开始转发 / 停止转发 | 启动或暂停发布媒体信息 |
| 发送测试文字 | 显示 `K1001 TEST 123`；随后选择“开始转发”恢复 |
| 开机自启动 | 在当前用户登录 Windows 后静默启动；新电脑首次使用需自行勾选 |
| 退出 | 停止转发并退出程序；不取消下次自启动 |

启用自启动后不要移动程序目录；若移动，请重新切换一次“开机自启动”。

## 歌词与兼容性

- 读取 QQ 音乐现有的本地 QRC/LRC 歌词缓存；不使用在线歌词搜索，不读取账号凭据，不修改播放器缓存。
- 根据歌名、歌手和时长匹配本地缓存，并用专辑区分版本；无法确定匹配时回退到歌名。
- 支持普通 LRC、QQ 冒号小数时间格式、QRC 逐字格式。输出原文整句，不含翻译、罗马音或逐字染色。
- 暂停、句间空隙和间奏时保留上一句歌词；拖动进度后重新定位。没有歌词或第一句尚未开始时显示歌名。
- 某首歌一直只有歌名时，可在 QQ 音乐中打开该曲歌词页，让播放器加载歌词；本程序会定期重试。
- 其他接入 Windows 系统媒体控制的播放器可以转发歌名等信息，但本版歌词适配仅针对 QQ 音乐。

默认歌词目录：

```text
%APPDATA%\Tencent\QQMusic\QQMusicCache\QQMusicLyricNew
```

要求 Windows 10 1809 及以上或 Windows 11、x64 电脑、支持相应蓝牙服务的设备。已在一台 Windows 11 电脑和 K1001 上验证歌词显示与基本同步；不同固件、QQ 音乐版本和蓝牙驱动可能影响兼容性。歌词缓存格式并非稳定的公开接口。

## 工作原理

```text
QQ 音乐 ── 歌曲信息 / 时间轴 ──► Windows 媒体会话
                                      │
QQ 音乐本地歌词缓存 ────────────────► 转发器
                                      │
                         当前歌词写入系统歌名字段
                                      │
                          Windows 蓝牙 AVRCP → K1001
```

程序不播放声音，也不修改默认音频输出。发布的是系统媒体会话，因此其他媒体外设或 Windows 媒体控件也可能看到歌词。屏幕支持的字段由设备决定；软件无法读取屏幕确认显示结果。

## 日志与配置

```text
%LOCALAPPDATA%\K1001Bridge\bridge.log
%LOCALAPPDATA%\K1001Bridge\settings.json
```

日志自动轮转，默认不记录歌名、歌手或歌词。自启动使用当前用户注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 下的 `K1001Bridge` 项。退出后删除程序目录即可移除程序；删除前请取消自启动。

## 从源码运行与构建

使用 Python 3.13 x64，在 PowerShell 中运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m unittest -v test_lyrics.py
.\.venv\Scripts\pythonw.exe tray.py
```

打包：

```powershell
.\build.ps1
```

产物位于 `dist/K1001-Bridge/`。`tray.py` 为默认入口，`bridge.py` 为系统媒体转发核心，`lyrics.py` 负责缓存匹配与时间轴解析。
